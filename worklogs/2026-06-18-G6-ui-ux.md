## What changed
Added a first-run, in-build telemetry consent modal so the G4 fun-gate cohort actually
opts in (the G3 build shipped README-only consent, which testers skip → empty telemetry).
Telemetry stays opt-in / default OFF: the prompt shows exactly once, on first launch,
over the main menu, blocking Start until the player answers. Enable turns telemetry on;
Not now leaves it off. Reused the existing G1 `Settings`/`Telemetry` infra and the single
`CONSENT_COPY` consent wording — no parallel persistence, no meta-schema bump.

## Files touched
- `systems/settings/settings.gd` — added the "asked" flag API: `KEY_ASKED`,
  `DEFAULT_TELEMETRY_ASKED=false`, `get_telemetry_asked()` / `set_telemetry_asked()` in
  the existing `"telemetry"` section of `user://settings.cfg`. Used to show the prompt once.
- `systems/settings/telemetry_consent_prompt.gd` — NEW. Greybox `CanvasLayer` modal
  (built inline, no .tscn/asset agent): dim input-blocking backdrop + panel with the
  shared `TelemetrySettingsPanel.CONSENT_COPY`, an Enable and a Not now button. On Enable →
  `Telemetry.set_enabled(true)`; on Not now → leaves telemetry OFF. Either choice calls
  `Settings.set_telemetry_asked(true)`, emits `choice_made(enabled)`, self-frees. Static
  `should_show()` gates on the asked-flag. "Not now" is focus-default (Enter ≠ silent opt-in).
- `scenes/game/main_game.gd` — wires the prompt: `_maybe_show_consent_prompt()` in `_ready()`
  after `_show_menu()`; disables the Start button + sets `_consent_pending` while up; restores
  the menu on `choice_made`. `_on_start_pressed()` ignores Start while the prompt is pending.
- `tests/test_telemetry_consent.gd` + `.tscn` — NEW headless SceneTree verification.
