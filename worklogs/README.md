# Worklogs

One worklog per consumed task — the audit trail the orchestrator enforces (`CLAUDE.md` →
"Work-product contract"). Every dispatched subagent writes one before its task counts as **Done**.

- **Filename:** `<YYYY-MM-DD>-<task-id>-<role>.md` (e.g. `2026-06-20-M1-03-ui-ux-designer.md`).
- **Template:** copy `TEMPLATE.md`.
- **Must name a real commit SHA.** No commit → not done.
- **Design deviations** recorded here are also appended to `design/DESIGN_DEVIATIONS.md`.

These are append-only history; don't edit a past worklog to rewrite what happened — add a new one.
