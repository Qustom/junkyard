## What changed
Built the M1 reward-beat sell screen — the post-run screen that visibly closes the
core loop. On every run-end (extract, death, timeout) it cashes out the banked junk
via F1's `sell_banked_junk()`, lists each sold item, animates a short count-up of the
persistent Money total, and gates a Continue button behind the tally. Greybox only
(default theme, plain containers). Driven entirely by `EventBus.run_ended` — pure
presentation over F1's logic, owns no Money and touches no save.

## Design deviations
- **`run_end(cause, payload)` → `run_ended(reason, duration_s, depth_reached)`**: the F2
  spec's code sketch listened to an idealized signal that does not exist. Reconciled to
  the As-Built EventBus contract (switch on `reason`, no payload dict). **Not a design
  change** — a reconciliation to canonical API.
- **Present on ALL THREE causes (extract / death / timeout)**: this is the **ratified**
  decision (E3 + F2 Open-question #1 recommendations, already in `DESIGN_DEVIATIONS.md`),
  not a new departure. Title by cause; conversion path identical; source `&"extract"` on
  extract, `&"pockets"` on death/timeout.
- **Count-up driven by a manual `_process` lerp, not a `Tween`**: Godot 4 has a standing
  regression where `Tween.TWEEN_PAUSE_PROCESS` does not reliably tick on a paused tree
  (godotengine/godot#81994, #67504). The screen runs while paused, so a manual lerp on a
  `PROCESS_MODE_ALWAYS` node is the robust equivalent. The spec only requires a count-up
  ("a Tween is enough", not required) — behaviourally identical, no design impact.
- **Audio "cha-ching" deferred** — audio isn't wired in M1 (per spec).

## Handoffs / follow-ups
- **What Continue is wired to:** the production `SellScreen` is decoupled — `Continue`
  unpauses, hides, and emits a local `continue_pressed` signal announcing intent. It does
  NOT own the restart/overworld flow. The **full run-start/overworld loop is deferred to
  G3**, which will subscribe to `continue_pressed` and decide where to go. The demo scene
  wires `continue_pressed` to a minimal stub (re-arm the fake-run buttons) so a human can
  cycle the beat now.
- **How to view the screen:** open `ui/sell/sell_screen_demo.tscn` in the editor and run
  it; click "Fake EXTRACT" to see the EXTRACTED beat with the count-up, or "Fake RUN LOST"
  for the timeout variant. Headless: `godot ui/sell/sell_screen_demo.tscn`.
- **Manual persistence acceptance** (literal "persists across runs"): extract, note Money,
  fully quit, relaunch the same slot, confirm the total — belongs on the G-series test
  checklist (F1 already saves before the animation, so quitting mid-tally keeps the total).
- **Visual polish / art / icons** handed to a human (greybox only here).
