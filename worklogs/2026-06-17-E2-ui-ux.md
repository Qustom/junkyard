## Design deviations
All of these are **reconciliations to the canonical As-Built contract, not design changes** — the
E2 spec's code sketches used idealized signal names that never existed. Per `M1_As_Built.md` the
As-Built doc wins on conflicts. None require Director sign-off.
- Spec sketch read `GameState.clock_remaining`/`clock_total` per-frame. Reality: no such members. **Reconciled** to listen to `EventBus.dive_clock_changed(current, maximum)` (A3 DiveClock node is the source of truth) — no polling of the clock at all.
- Spec sketch used `EventBus.inventory_changed(run_value, count)`. Reality: `run_inventory_changed(used_slots, max_slots)` (D1); haul value comes from `GameState.run_haul_value()`. **Reconciled.**
- Spec sketch used `EventBus.depth_changed(depth)`. Reality: no such signal. **Reconciled** to read `GameState.current_depth`, refreshed on `run_inventory_changed` / `band_entered` / run boundaries.
- Spec sketch used `EventBus.gate_in_range`/`gate_out_of_range`. Reality: no such signals. **Reconciled** to `interactable_focused(target)`/`interactable_unfocused(target)` (A2), filtered to the gate by matching `interactable_id == &"gate"` (E1's authored id), so junk focus never raises the extract prompt.
- Did not embed the existing `ui/dive_clock_meter` node — it only does white/red at a warn fraction. E2 needs the full green→amber→red ramp + urgency threshold, so the HUD drives its own ProgressBar off the same `dive_clock_changed` signal. The dive_clock_meter remains usable standalone elsewhere; no file touched.
- Added a new `hud_strings.csv` + registered it in `project.godot` rather than appending to D2's `ui/inventory/inventory_strings.csv` (forbidden this wave). `project.godot` is not on the no-touch list; edit was additive (one array entry).

## Open playtest-tuning knobs (G4 fun gate)
- `urgency_fraction` (default **0.25**) — clock fraction at/below which the Holding label pulses. Single `@export` tunable per spec Open-question #2.
- `pulse_speed` (default 6.0) — urgency pulse rate.
- Juice level is intentionally **minimal**: green→amber→red tint + one urgency pulse only. No vignette / slow-mo / heartbeat (spec Open-question #2 says ship minimal, dial up post-playtest).
- Depth (not live distance-to-gate) is the cost-of-pushing signal for M1 — B3 exposes `dist_to_gate` on `PlacedPiece` but there is no live player-distance signal yet; spec Open-question #4 recommends distance-to-gate as a post-M1 upgrade.
