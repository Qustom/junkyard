## Design deviations
- **Worklog filename.** The N0 spec's DoD names `worklogs/2026-06-27-N0-character-animator.md`; the build dispatch named
  `worklogs/2026-06-27-N0-general-purpose.md`. Followed the dispatch (the only contributing agent this pass was
  general-purpose; the art was pre-produced upstream). Same task, one worklog — no contract change.
- **`.tres` authoring method.** The spec's "authoring note" recommends building the SpriteFrames in the editor (drag frames
  onto a throwaway `AnimatedSprite2D`) and explicitly allows "a generator script under `tools/`" as an acceptable
  build-aid alternative. Used the generator-script path (headless-friendly, deterministic, hand-verifiable), but kept the
  script in `/tmp` (NOT committed under `tools/`) since it is a one-shot build aid, not a maintained tool. Output verified.
- Otherwise fully on-spec. Not appended to `DESIGN_DEVIATIONS.md` (no GDD/TDD/design departure — these are process notes).
